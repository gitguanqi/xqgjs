    怎么跑

    页面需要通过 HTTP 打开，否则 type="module" 与 fetch 会被浏览器拦住：

    npm install
npm run serve
# 然后打开 http://127.0.0.1:4001/test/index.html

    自动化验证也可以直接跑 npm test，它包含单元测试、产物一致性检查、类型检查和打包契约。
